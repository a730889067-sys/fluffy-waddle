# TESTCRAFT

منصة تعليمية تجريبية تجمع بين المذاكرة والتحديات وبطاقات الاسترجاع وأدوات إعداد الاختبارات.

## تشغيل الموقع
- افتح الرابط المنشور عبر GitHub Pages بعد تفعيله من إعدادات المستودع.
- الصفحة الرئيسية هي `index.html` ولا تحتاج إلى تثبيت حزم أو بناء.
- يعمل الموقع على الهاتف والكمبيوتر.

## ما يتضمنه النموذج الأولي
- واجهة عربية مع خيارات للإنجليزية والإسبانية والفرنسية.
- تحديات قصيرة في الرياضيات والعلوم واللغة.
- بطاقات مراجعة.
- أداة للمعلم لإضافة أسئلة واختيارات وإعداد ورقة للطباعة مع مفتاح الإجابة.
- حفظ النقاط والأسئلة المضافة محليًا في المتصفح.

## حدود النسخة الحالية
هذه نسخة MVP تجريبية. لا تتضمن بعد حسابات مستخدمين حقيقية أو مزامنة بين الأجهزة أو صفوفًا مشتركة أو ذكاءً اصطناعيًا أو بوابة دفع أو رفع ملفات PDF أو فيديو وصوت. البيانات محفوظة على الجهاز نفسه فقط. لا تستخدمها لحفظ بيانات طلاب حساسة.

## النشر
في GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.
