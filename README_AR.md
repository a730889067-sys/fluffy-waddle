# TESTCRAFT

منصة تعليمية تجريبية تجمع بين التعلم بالمهمات القصيرة والاختبارات وبطاقات الاسترجاع وأدوات إعداد الاختبارات.

## ما الذي يعمل في هذه النسخة؟

- واجهة متجاوبة للهاتف والكمبيوتر بتصميم داكن.
- مسارات أسئلة تجريبية في الرياضيات والعلوم واللغة.
- نقاط خبرة ومستويات وسلسلة أيام ومهمة يومية.
- حفظ الإجابات الخاطئة وإضافتها إلى قائمة المراجعة.
- بطاقات استرجاع مع إمكانية وضع البطاقة في قائمة «أتقنتها» أو «أحتاج مراجعة».
- مساحة للمعلم لإضافة أسئلة بأربعة خيارات.
- استيراد وتصدير بنك الأسئلة بصيغة JSON.
- إنشاء نموذجين مختلفين A وB مع تبديل ترتيب الاختيارات ومفتاح إجابة منفصل لكل نموذج.
- حفظ محلي في المتصفح، ونسخة احتياطية قابلة للتنزيل.
- إعداد PWA/Service Worker لتثبيت الموقع وتشغيل الملفات المخزنة بعد زيارة الموقع أول مرة.
- تغيير لغة بعض عناصر التنقل والرسائل إلى الإنجليزية والإسبانية والفرنسية؛ ما زالت ترجمة جميع الدروس والمحتوى غير مكتملة.

## حدود مهمة — اقرأ قبل الاستخدام

هذه نسخة أولية (MVP)، وليست منصة تجارية مكتملة بعد:
- لا توجد حسابات مستخدمين أو تسجيل دخول.
- لا توجد صفوف مشتركة أو منافسة حقيقية بين الطلاب.
- البيانات محفوظة في متصفح الجهاز نفسه فقط؛ لا تتم مزامنتها بين الأجهزة.
- لا يوجد ذكاء اصطناعي أو توليد أسئلة من ملفات PDF.
- لا يوجد رفع ملفات أو معالجة فيديو وصوت.
- لا توجد بوابة دفع أو اشتراكات أو نظام إدارة اشتراكات.
- تبديل دور الطالب/المعلم داخل الواجهة للتنقل فقط، وليس نظام صلاحيات أو حماية حسابات.
- تشغيل دون اتصال يحتاج إلى فتح الموقع أول مرة عبر HTTPS حتى تُخزّن موارده في المتصفح. قد تختلف إمكانية التثبيت حسب المتصفح والجهاز.

لا تحفظ بيانات شخصية أو درجات حساسة للطلاب في هذه النسخة، ولا تعتمد على مفتاح الإجابة دون مراجعة المعلم.

## النشر على GitHub Pages

يعمل GitHub Actions على فحص صياغة JavaScript والملفات اللازمة قبل النشر. بعد نجاح الفحص، تُنشر ملفات الموقع تلقائيًا عبر GitHub Pages.

لأول تفعيل، افتح المستودع ثم:
1. Settings
2. Pages
3. تأكد أن النشر عبر GitHub Actions متاح.
4. افتح تبويب Actions لمراجعة نتيجة مسار TESTCRAFT - Validate and Deploy.

عنوان الموقع يظهر في إعدادات Pages بعد نجاح أول عملية نشر.

## العمل محليًا

افتح ملف index.html في خادم محلي أو انشر المجلد على استضافة HTTPS. بعض ميزات PWA والعمل دون اتصال لا تعمل عند فتح الملف مباشرة بصيغة file://.

## خارطة التطوير التالية

1. استكمال ترجمة جميع الواجهات والأسئلة.
2. دعم تصدير الاختبارات كملف PDF مباشرة.
3. إضافة حسابات آمنة وخادم وقاعدة بيانات ومزامنة الفصول.
4. رفع ملفات الدروس ثم إضافة معالجة واستخراج أسئلة وفق حدود خدمة مجانية موثوقة.
5. إضافة المنافسات والمهام الجماعية بعد توفير التخزين والمزامنة.

**الشفافية:** لا يُدّعى أن أي ميزة في خارطة التطوير موجودة حاليًا.
