# ANIME ART ACADEMY – أكاديمية رسم الأنمي

تطبيق Android تعليمي باللغة العربية لتعلّم رسم الأنمي دون اتصال بالإنترنت.

## ما تتضمنه النسخة الحالية (0.8.0)

- مسار أساسيات: بناء الرأس والوجه، العين، الشعر، الظل والإضاءة، نسب الجسم، وضعيات الحركة، اليدان، وطيات الملابس.
- دروس تدريبية لملامح سون جين وو وغوجو ولوفي وتانجيرو.
- رسومات توضيحية متجهية أصلية تتدرج مع خطوات الدرس.
- صور مرجعية مرسومة ومضمنة دون إنترنت لسون جين وو وغوجو ولوفي وتانجيرو.
- مساحة الرسم مدمجة مع مخطط الخطوة نفسها؛ ارسم فوق خطوط مرجعية باهتة بدل الانتقال إلى مساحة منفصلة.
- شرح تفصيلي لموضع الخط الحالي وخطوات تنفيذه، وتظهر خطوة واحدة فقط في كل مرة.
- ألوان فاتحة للواجهة والخلفية مع ألوان تمييز هادئة.
- مساحة رسم تعمل باللمس، مع ألوان متعددة، وممحاة واضحة، وثلاثة أحجام مباشرة للقلم.
- زر الرجوع في الهاتف يرجع خطوة تعليمية، وعند أول خطوة يعود إلى قائمة الدروس بدل إغلاق التطبيق.
- وضع تكبير مستقل: استخدم إصبعين للتكبير والتحريك، ثم عد إلى وضع الرسم للرسم الدقيق دون رسم عرضي أثناء التكبير.
- تراجع وإعادة ومسح، وتصدير العمل كصورة PNG عبر نافذة الحفظ في Android.
- يحفظ آخر درس وآخر خطوة وعدد الدروس المكتملة محليًا على الهاتف، ويتيح متابعة الدرس من مكان التوقف.
- يحفظ خطوط التدريب تلقائيًا وبشكل مستقل لكل درس، فتظل الرسمة عند الخروج والعودة إلى الدرس، حتى دون اتصال بالإنترنت.
- لا يحتاج التطبيق إلى حساب أو API أو اتصال إنترنت وقت الاستخدام.

## متطلبات البناء

- JDK 17
- Android SDK مع منصة Android 35
- Gradle متوافق مع Android Gradle Plugin 8.7.3

من مجلد المشروع:

```bash
gradle assembleDebug
```

ينتج APK التجربة هنا:

```
app/build/outputs/apk/debug/app-debug.apk
```

يُنفذ GitHub Actions عملية البناء عند تحديث ملفات هذا المشروع، ويمكن تشغيله يدويًا من تبويب Actions.

## حالة التحقق

- تم التحقق من نجاح GitHub Actions في بناء APK بنجاح بتاريخ 2026-11-25.
- تم التحقق من وجود ملف APK داخل artifact الناتج وتنزيله واستخراجه.
- لم يُختبر التطبيق بعد على أجهزة Android فعلية؛ لذلك لا أزعم ضمان خلوه من جميع أخطاء التشغيل على كل هاتف.

## ما يزال بحاجة إلى تطوير

هذه نسخة تطويرية قابلة للتجربة، وليست إصدارًا نهائيًا تجاريًا. في 0.7.0 أعيد تصميم شاشة الدرس لتضم الشرح والرسم في لوحة واحدة، وأضيفت صور مرجعية مرسومة للشخصيات، وثيم فاتح، والتحكم بزر الرجوع. وفي 0.8.0 أضيف وضع تكبير وتحريك بإصبعين مع فصل وضع الرسم عنه. الرسومات المرجعية أصلية بأسلوب أنمي مبسط للتدريب وليست صورًا رسمية أو نسخًا مطابقة لإطارات المسلسل. كما أن النسخة لا تتضمن حاليًا طبقات رسم أو تكبيرًا وتحريكًا للوحة أو مزامنة سحابية للتقدم. تقدم الدروس يُحفظ محليًا على الجهاز، ويمكن تصدير رسومات اللوحة يدويًا بصيغة PNG.

الرسومات المضمنة أصلية ومبسطة للتدريب؛ لا تُضمّن صورًا رسمية أو ملفات فنية محمية بحقوق الأنمي.
