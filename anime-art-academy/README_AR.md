# ANIME ART ACADEMY – أكاديمية رسم الأنمي

تطبيق Android تعليمي باللغة العربية لتعلّم رسم الأنمي دون اتصال بالإنترنت.

## ما تتضمنه النسخة الحالية (0.4.0)

- مسار أساسيات: بناء الرأس والوجه، العين، الشعر، الظل والإضاءة، نسب الجسم، وضعيات الحركة، اليدان، وطيات الملابس.
- دروس تدريبية لملامح سون جين وو وغوجو ولوفي وتانجيرو.
- رسومات توضيحية متجهية أصلية تتغير تدريجيًا مع الانتقال بين خطوات الدرس.
- مساحة رسم تعمل باللمس، مع ألوان متعددة، ممحاة، وثلاثة أحجام عملية للقلم.
- تراجع وإعادة ومسح، وتصدير العمل كصورة PNG عبر نافذة الحفظ في Android.
- يحفظ آخر درس وآخر خطوة وعدد الدروس المكتملة محليًا على الهاتف، ويتيح متابعة الدرس من مكان التوقف.
- لا يحتاج التطبيق إلى حساب أو API أو اتصال إنترنت وقت الاستخدام.

## متطلبات البناء

- JDK 17
- Android SDK مع منصة Android 35
- Gradle متوافق مع Android Gradle Plugin 8.7.3

من مجلد المشروع:

```bash
gradle assembleDebug
```

ينتج APK التجربة هنا:

```
app/build/outputs/apk/debug/app-debug.apk
```

يُنفذ GitHub Actions عملية البناء عند تحديث ملفات هذا المشروع، ويمكن تشغيله يدويًا من تبويب Actions.

## حالة التحقق

- تم التحقق من نجاح GitHub Actions في بناء APK بنجاح بتاريخ 2026-11-25.
- تم التحقق من وجود ملف APK داخل artifact الناتج وتنزيله واستخراجه.
- لم يُختبر التطبيق بعد على أجهزة Android فعلية؛ لذلك لا أزعم ضمان خلوه من جميع أخطاء التشغيل على كل هاتف.

## ما يزال بحاجة إلى تطوير

هذه نسخة أولية متقدمة قابلة للتجربة، وليست إصدارًا نهائيًا تجاريًا. الرسوم التوضيحية الحالية مخططات تدريبية أصلية مبسطة تتدرج مع خطوات الدروس، وليست رسومات احترافية مفصلة لكل شخصية. كما أن النسخة لا تتضمن حاليًا طبقات رسم أو تكبيرًا وتحريكًا للوحة أو مزامنة سحابية للتقدم. تقدم الدروس يُحفظ محليًا على الجهاز، ويمكن تصدير رسومات اللوحة يدويًا بصيغة PNG.

الرسومات المضمنة أصلية ومبسطة للتدريب؛ لا تُضمّن صورًا رسمية أو ملفات فنية محمية بحقوق الأنمي.
