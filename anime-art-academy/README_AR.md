# ANIME ART ACADEMY – أكاديمية رسم الأنمي

تطبيق Android تعليمي باللغة العربية لتعلّم رسم الأنمي دون اتصال بالإنترنت.

## ما تتضمنه النسخة الحالية (0.2.0)

- مسار أساسيات: بناء الرأس والوجه، العين، تقسيم الشعر إلى خصل، والظل والإضاءة.
- دروس تدريبية لملامح سون جين وو وغوجو ولوفي وتانجيرو.
- رسومات توضيحية متجهية أصلية تتغير تدريجيًا مع الانتقال بين خطوات الدرس.
- مساحة رسم تعمل باللمس، مع خمسة ألوان للقلم وثلاثة أحجام عملية.
- التراجع عن آخر خط، مسح اللوحة، وتصدير العمل كصورة PNG من خلال نافذة الحفظ في Android.
- لا يحتاج التطبيق إلى حساب أو API أو اتصال إنترنت وقت الاستخدام.

## متطلبات البناء

- JDK 17
- Android SDK مع منصة Android 35
- Gradle متوافق مع Android Gradle Plugin 8.7.3

من مجلد المشروع:

```bash
gradle assembleDebug
```

ينتج APK التجربة هنا:

```
app/build/outputs/apk/debug/app-debug.apk
```

كما ينفذ GitHub Actions عملية البناء عند تحديث ملفات هذا المشروع، ويمكن تشغيله يدويًا من تبويب Actions.

## ما يزال بحاجة إلى استكمال واختبار

هذه نسخة تطويرية قابلة للتجربة وليست إصدارًا نهائيًا تجاريًا. لم يثبت بعد نجاح بناء APK على GitHub Actions أو اختباره على أجهزة Android فعلية. لا تتضمن النسخة حاليًا طبقات رسم، تكبيرًا وتحريكًا للوحة، ممحاة مستقلة، أو حفظ تقدم الدروس بين مرات التشغيل. كما أن الرسوم التوضيحية الحالية مخططات تعليمية مبسطة وليست دروسًا احترافية مكتملة لكل شخصية.

الرسومات المضمنة أصلية ومبسطة للتدريب؛ لا تُضمّن صورًا رسمية أو ملفات فنية محمية بحقوق الأنمي.
