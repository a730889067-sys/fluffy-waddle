# ANIME ART ACADEMY – أكاديمية رسم الأنمي
تطبيق Android تعليمي باللغة العربية، مصمم للعمل دون اتصال.

## النسخة التأسيسية
- دروس متدرجة بالعربية: أساسيات الوجه والعين، ودروس تدريبية لشخصيات أنمي معروفة.
- لوحة رسم باللمس مع التراجع والمسح.
- لا يتطلب حسابًا أو API أو اتصال شبكة أثناء الاستخدام.
- GitHub Actions لبناء APK تلقائيًا.

## البناء
يتطلب JDK 17 و Android SDK:
`gradle assembleDebug`
ملف APK: `app/build/outputs/apk/debug/app-debug.apk`

## ما لم يكتمل بعد
هذه نسخة أولية وليست الإصدار النهائي. الرسوم التعليمية التوضيحية التفصيلية، حفظ الأعمال إلى المعرض، الطبقات، التكبير، والفرش المتقدمة تحتاج مراحل تطوير واختبار إضافية. يجب استخدام رسومات أصلية أو مرخصة وعدم تضمين صور رسمية محمية من الأنمي.
